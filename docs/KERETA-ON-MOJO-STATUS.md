**Architecture (all in `games/data/`, loaded in this order by `games/mojo-pack.js`; `?story=malivlak|hellbent` swaps only the first file):**
`kereta-pack-levels[-<story>].js` (levels, LIB art keys, STORY meta: heroes {form: {sprite}}, narrator art, saveKey, logo, cast, pins) -> `kereta-pack.js` (art table, rails/ground, hub, map, ambient layer, headroom row, objArt) -> `kereta-cam.js` (Linus stands) -> `kereta-goals.js` (goal checklist, bubbles, ghosts, NAMES name-tag table, verbWords/goalText, load/unload anim, tag nudge) -> `kereta-story.js` (def.fx helpers, tow rig + chain + whip, cave, James's shot, cab2/front riders, hopLate) -> `kereta-cine.js` (def.onPlay: speed/heavy/brake/start/end, letterbox, zoom, slideIn) -> `kereta-life.js` (idles, pose swaps, deer/birds, fringe, shadows, motes). Engine hooks in `mojo-swoptops.js`/`prog-grid.js` are inert without `?pack=`: onHud, onPlay, onLoad, onUnload, goalText, verbWords, `lv.autoAim`.
**Level data fields the pack understands:** `cine {speed,heavy,brake{obj},start,end}`, `tow`, `cave`, `shot`, `gate`, `pillars`, `monument`, `sky:['plane']`, `ride {cab2,front}`, `hopLate`, per-beat `decor/vis/hide/start/fx/mood/terrain/cave`, `cards` (story cards, `headline` = newspaper), decor `react` (pose swap near Linus), `label`.
**Gates:** `QA_STORY=brave|malivlak|hellbent node tools/qa-kereta-pack.mjs` (run all three; `--headless` skips the browser half) and `node tools/qa-prog-grid.mjs`. Server localhost:8081. A level is accepted only when solvable, `slots = shortest+2..6`, `budget >= shortest`, bo line <= 8 words and names the objective, consecutive levels differ in palette signature.
**Rules the gates enforce (do not fight them):** one Goro per board; no two figures of one character on a beat; no figure or rider on row 0 (the pack adds a headroom row); animals never on rail cells; every figure's tag = name-table entry of its drawn art; no two name tags overlap; every VFX id must exist, be cc0/public-domain, not electric (no `bk-spark-*`/`bk-trace-*`), not `bk-smoke-puff`; screen-blend effects must be drawn with mix-blend-mode screen. Use `def.fx.puff/dust/sparks` for smoke and dust, never raw ids.
**Traps learnt:** (1) patrol blocks a rail forever unless its path leaves the main row or a WAIT is part of the solution (check with `PG.solve`; the solver depth is ~16 moves, keep levels short); (2) a stop's objective needs the item parcels near it or the budget explodes; (3) `rev`/headroom shifts coordinates: author maps WITHOUT the headroom row, the pack adds it; (4) each storyline uses only its own cast (gate FOREIGN map), so Malivlak levels may not use story-char/* and Hellbent may not use malivlak-char/*; (5) cast keys listed in `kereta-cast.js` per scenario must be used (decor, rider, `react`, cab, ride) or added to EXCLUDED in the gate with a reason; (6) sprites under `assets/db/lib/mojo-*` and shared dirs are being re-cut by main: transient "request failed" in the gate is not yours, rerun.
