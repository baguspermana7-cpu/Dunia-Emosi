# Mojo Swoptops --- 50 Transformation & Scenario Design Bible

**Version:** 1.0\
**Scope:** **50 functional transformations × 5 core scenarios = 250
scenario families**\
**Target:** Grade 1--2 SD (approx. 6--8 years)\
**Companion:** *Mojo Swoptops: Swop, Plan & Rescue PRD*

> **IP / production note:** the Swop-Top concept is the franchise
> anchor. This catalogue intentionally includes many **proposed
> game-expansion forms**. Any form not present in approved
> series/licensor material must remain a proposal until IP approval.

## Core rule

Every form must alter the actual command vocabulary. The child must be
able to answer both **"What should Mojo become?"** and **"What sequence
should Mojo execute?"**. Transformation may occur inside the program
itself.

Universal loop:

`OBSERVE → IDENTIFY PROBLEM → SWOP/KEEP FORM → PROGRAM → RUN → VEHICLE ACTION → EDUCATIONAL ACTION → COMPLICATION → RE-SWOP → RESCUE`

## Scenario authoring standard

Every scenario below is a **scenario family**, not one fixed level. Each
should be authored in 4--7 variants by changing grid, route, quantities,
language payload, obstacles, command budget, collectibles, or second
transformation. Mistakes enter Debug mode rather than Game Over.

# Cross-Transformation Mission Recipes

## 1. Landslide → Fire → Rooftop Rescue

`DOZER → FIRE → CHERRY PICKER`\
Clear debris, navigate to the building, extinguish fire, discover a high
rescue target, re-Swop and rescue.

## 2. Flooded Construction Site

`BOAT → CRANE → DUMPER`\
Navigate current, recover a structural part, lift/place it, then deliver
repair material.

## 3. Broken Bridge

`EXCAVATOR → CEMENT MIXER → BRIDGE LAYER`\
Prepare support, solve material quantities, pour foundation, measure the
gap and deploy the correct bridge.

## 4. Warehouse Emergency

`FORKLIFT → MOBILE WORKSHOP → TOW TRUCK`\
Move blocking pallets, identify and use the correct repair tool, then
recover the disabled vehicle.

## 5. Mountain Route

`MONSTER TRUCK → CHOPPER → AMBULANCE`\
Cross rough terrain, discover an impassable section, fly to the target,
then complete safe transport.

## 6. River Cargo Chase

`RACER → AMPHIBIOUS RESCUE → BOAT` Chase cargo on land, transition into
water, then tow it to the correct destination.

## 7. Winter Access

`SNOW PLOW → STREET SWEEPER → SCHOOL BUS` Clear route, clean remaining
hazard tiles, then execute ordered passenger pickup.

## 8. Underground Shortcut

`DRILL RIG/TUNNEL BORER → MOBILE WORKSHOP → ROAD ROLLER` Create passage,
repair a mechanism, then prepare the route for normal traffic.

# Swop Selector UX

Do **not** show 50 choices simultaneously. Early missions show 2--3
contextual candidates. Later, group forms by function:

-   **Clear/Build:** Dozer, Excavator, Backhoe, Paver, Roller, Bridge
    Layer
-   **Lift/Reach:** Crane, Cherry Picker, Scissor Lift, Telehandler,
    Forklift
-   **Fast/Traverse:** Racer, Monster, Jumper, Jet
-   **Water:** Boat, Amphibious, Hovercraft, Submarine
-   **Rescue/Transport:** Chopper, Ambulance, Tow Truck, Bus, Shuttle
-   **Special Tools:** Magnet, Vacuum, Grapple, Drill, Mobile Workshop

# Unlock Recommendation

**Tier 1:** Fire, Dozer, Crane, Chopper, Racer, Boat, Dumper, Cherry
Picker.\
**Tier 2:** Jumper, Monster, Tow Truck, Excavator, Forklift, Water
Tanker, Mobile Workshop, Bridge Layer.\
**Tier 3:** themed construction, farm, snow, rail, underwater, delivery
and space forms.\
**Tier 4:** overlapping-capability forms used in open puzzles with
multiple valid solutions.

# Production Requirement Per Transformation

For every one of the 50 forms create:

-   approved silhouette/model;
-   Swop transformation animation;
-   idle/move/turn states;
-   unique action animations;
-   command icons;
-   unique SFX;
-   blocked/failure feedback;
-   success animation;
-   capability tags;
-   interaction tags;
-   tutorial vignette;
-   five core scenario families;
-   4--7 variants per scenario family;
-   Indonesian + English narration;
-   hint ladder;
-   accessibility labels.

At minimum this catalogue therefore supports **250 core scenario
families**. At 4--7 variants each, the content system can yield
approximately **1,000--1,750 authored scenario variants** without
changing the core programming loop.

# Level Approval Checklist

-   [ ] Transformation is functionally required or is a valid
    alternative solution.
-   [ ] Unique action is explicitly programmed by the child.
-   [ ] Route planning matters.
-   [ ] Educational interaction affects world state.
-   [ ] Failure is understandable and debug-friendly.
-   [ ] Scenario does not play identically with Normal Mojo.
-   [ ] Cause/effect is visible.
-   [ ] Alternative valid solutions are not arbitrarily rejected.
-   [ ] Text burden is appropriate for Grade 1--2.
-   [ ] The rescue/repair has a satisfying visual payoff.

# Final Design Identity

The catalogue must preserve one consistent mental model:

> **Problem → choose capability → transform → program movement and
> action → run → observe → debug/re-Swop → solve.**

The large number of forms is valuable only if each one creates a
genuinely different **verb**, **problem class**, and **educational
opportunity**.
