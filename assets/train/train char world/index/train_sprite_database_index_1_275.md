# Train Character Sprite Database Index 1–275
Purpose: master index for image-generation parts, arranged by collection sequence.

**Index structure:**
- **1–250:** global railway evolution collection, oldest to newest.
- **251–275:** Indonesia-focused Part 11, from heritage steam locomotives to modern KAI/KRL/LRT/Whoosh rolling stock.

**Design control notes for image generation:** strict side view, all facing one direction, no faces, no humans, no mascot body parts, white background, 5×5 grid per part.

> Note: Some late-modern items are platform/family references where a single trainset/model has multiple sub-variants or production batches.
