Definition of Done — Fitur AAA untuk Anak 5-9 Tahun

Sebelum sebuah ide dipromote dari "ide AAA" menjadi "fitur yang dibangun", ia harus memenuhi minimal 4 dari 6 kriteria di bawah. Kriteria ini adalah filter etika + edukasi yang diterapkan ke setiap idea card sebelum masuk sprint.

Kriteria 1

Learning Impact

Fitur secara langsung menaikkan kalistung (math/reading/writing) atau emotional literacy. Bukan sekadar polish visual atau retention hook.

Kriteria 2

Short-Session Fit (3-8 menit)

Loop utama selesai dalam 3-8 menit. Tidak boleh memaksa sesi panjang. Tidak boleh time-gated yang menahan anak di app.

Kriteria 3

Parent-Safe

Tanpa chat publik, profil publik, monetisasi anak, data sensitif, kamera tanpa parent gate, dan tanpa social pressure.

Kriteria 4

Existing Game Fit

Memperkuat game yang sudah ada (G4/G6/G8/G9/G10/G13) — bukan mengalihkan resource ke spin-off baru yang menggeser fokus belajar.

Kriteria 5

Pokemon Hook tanpa Ketergantungan

Pokemon/monster jadi motivasi, tapi mekanik tetap valid jika sprite/lore di-swap menjadi original creature. Tidak mengunci IP.

Kriteria 6

MVP Feasible (1-4 minggu)

Versi paling kecil bisa shipped dalam 1-4 minggu oleh tim kecil. Jika MVP >4 minggu, fitur harus di-reshape atau di-park.

Floor: 4 dari 6 kriteria harus terpenuhi. Jika kurang dari 4 → fitur diparkir sampai bisa di-reshape ulang. Semua AI / voice / kamera / monetisasi dijeda sampai safety spec dan privacy policy matang.

6 Prinsip Urutan Build (Tidak Boleh Dibalik)

Urutan ini diturunkan dari prinsip pedagogis: anak tidak butuh "fitur lebih banyak", anak butuh "feedback yang benar saat salah". Karena itu visual hub, online, dan live-ops harus menunggu sampai loop belajar inti sudah punya pengukuran dan koreksi.

  1. Stabilitas dulu, fitur baru kemudian. Tidak ada fitur baru dibangun di atas game yang masih crash, kehilangan progress, atau punya error fatal di console. Audit Sprint 0 adalah prasyarat semua roadmap. Never reverse
  2. Learning feedback sebelum reward. Sebelum menambah XP/badge/cosmetic, anak harus mendapat hint yang benar saat salah (off-by-one, salah operator, salah operand). Reward tanpa feedback hanya melatih "tap cepat", bukan belajar.
  3. Skill tracking sebelum daily routine. Daily quest tidak boleh acak. Ia harus mengambil dari rekomendasi skill yang lemah berdasarkan attempt log. Karena itu Mastery Trees (#42) + Learning Event Log mendahului Daily Training (#31).
  4. Daily routine sebelum hub 2D. Pulau Emosi (#1) baru ditambahkan setelah anak punya loop harian yang sehat. Hub tanpa daily target = launcher yang cantik tanpa arah.
  5. Local sebelum online. Semua MVP (mastery, daily quest, co-op, gift, recap) dibangun versi local-only dulu. Pindah ke server hanya setelah privacy policy, parent account, dan compliance dasar siap.
  6. Tidak ada live-ops, PvP, marketplace, atau LLM untuk anak dalam 12 bulan pertama. Bukan karena tidak menarik — karena child safety dan moderation infrastructure belum cukup matang. Strict floor

Write Path (pseudocode)
function logAttempt(ev) { ev.v = 1; ev.ts = ev.ts || (performance.timeOrigin + performance.now()); ev.errorClass = ev.errorClass || classifyError(ev); pushRing('dunia-events-v1-' + ev.avatar, ev, 2000); bumpSkillStats(ev.avatar, ev.skill, ev); if (window.RZ_EVT) RZ_EVT.emit('learning:attempt', ev); } function classifyError(ev) { if (ev.correct) return 'unknown'; if (ev.game === 'g10' && typeof ev.wrongValue === 'number') { if (Math.abs(ev.wrongValue - ev.expected) === 1) return 'off_by_one'; // swap operator detect: wrong = a*b when expected a+b etc. if (isOpSwap(ev)) return 'wrong_op'; return 'wrong_operand'; } if (ev.game === 'g9') return ev.hintLevel === 0 ? 'stroke_start' : 'stroke_order'; return 'unknown'; }
Edge Cases
  • Clock skew / DST: never use Date.now() for ordering across events of same skill — use a monotonic counter inside bumpSkillStats.
  • Storage quota: if setItem throws QuotaExceededError, drop oldest 30% events and retry once.
  • Corrupt JSON: load returns empty ring + emits one telemetry warning (silent for the child).
  • Multi-tab: storage storage event listener refreshes in-memory cache; no merge conflicts since events are append-only.
Tests
  • 1000 sequential logAttempt — ring stays at ≤2000 with newest first.
  • Inject QuotaExceededError — older events dropped, new event lands.
  • Inject malformed JSON — load recovers without throwing.
  • Two tabs writing simultaneously — neither tab loses its own writes.

B · Mastery Formula (with decay + cold-start)

Used by #42, #26, #39
Impact: Foundational Safety: Low Sprint 3
Formula
// Weighted moving accuracy with exponential recency decay // + cold-start floor to avoid premature unlock const LAMBDA = 0.08; // decay per day (~half-life 8.7 days) const MIN_ATTEMPTS = 6; // below this, mastery clamped < unlock floor const UNLOCK_FLOOR = 0.70; // child node unlocks when ALL parents >= 0.70 function masteryOf(skill, nowDays) { const evs = recentEvents(skill, 60); // last 60 days if (evs.length < MIN_ATTEMPTS) { // cold start: mastery exists but not high enough to unlock return Math.min(0.55, sampleAccuracy(evs)); } let num = 0, den = 0; for (const ev of evs) { const ageDays = nowDays - ev.tsDays; const w = Math.exp(-LAMBDA * ageDays); // hint usage and wrong answers count progressively const credit = ev.correct ? (1 - 0.15 * ev.hintLevel) : 0; num += w * credit; den += w; } return den === 0 ? 0 : num / den; } function nodeUnlocked(node) { return node.parents.every(p => masteryOf(p) >= UNLOCK_FLOOR); }
Why these constants
  • LAMBDA = 0.08 — anak yang istirahat seminggu masih punya mastery ~0.57 dari peak (tidak hilang sepenuhnya). Setelah sebulan turun ~0.09 dari peak (perlu refresh).
  • MIN_ATTEMPTS = 6 — cegah anak yang kebetulan 3x benar berturut langsung dianggap menguasai. Sample size minimum kecil tapi nyata.
  • UNLOCK_FLOOR = 0.70 — bukan 1.0. Anak boleh ke topik berikutnya saat "cukup bisa", tidak menunggu sempurna.
  • hint discount 0.15 — jawaban benar dengan 2 hint dapat 0.70 kredit. Hint dipakai = belajar, bukan dosa.
Edge Cases
  • Anak baru (0 event): semua mastery 0, hanya root skill yang tersedia.
  • Anak hiatus 60 hari: mastery jatuh ke cold-start floor; UI menampilkan "Refresh dulu" daripada langsung uji.
  • Anak speedrun benar semua tanpa hint: maksimal 1.0; UI tetap menampilkan "Excellent" tanpa shame kalau salah-lalu-benar.
Tests
  • Inject 6 benar tanpa hint hari ini → mastery ≥ 0.85.
  • Inject 6 benar dengan 3 hint masing-masing → mastery ≈ 0.55 (di bawah unlock floor).
  • Inject 10 benar pada hari -30 + 0 hari ini → mastery ≈ 0.62 (decay nyata).
  • Inject 5 benar + 1 salah, semua hari ini → mastery ≈ 0.83.

D · Stroke Match Algorithm (G9 handwriting)

Used by #29
Impact: High Safety: Low Sprint 5
Inputs
  • target: Stroke[] — array of polylines (start → end), normalized to 0..1 canvas.
  • user: Stroke[] — strokes captured between pointerdown and pointerup, normalized.
Scoring Pseudocode
function scoreStrokes(target, user) { if (user.length === 0) return { total: 0, parts: zeroParts() }; // 1) Start-point match: distance dari user[i].start ke target[i].start const startScore = avg(target.map((t,i) => { if (!user[i]) return 0; const d = dist(t.points[0], user[i].points[0]); return clamp01(1 - d / 0.18); // tolerance 18% canvas })); // 2) Stroke order: pakai DTW antara index target dan urutan user const orderScore = dtwOrderMatch(target, user); // 3) Path closeness: untuk tiap stroke, hitung mean distance dari // titik user yang di-resample 32 titik ke segmen target terdekat const closeScore = avg(target.map((t,i) => { if (!user[i]) return 0; const pts = resample(user[i].points, 32); const meanDist = mean(pts.map(p => distToPolyline(p, t.points))); return clamp01(1 - meanDist / 0.22); })); // 4) Completion: berapa stroke target yang tercakup const compScore = clamp01(user.length / target.length); const total = 0.25 * startScore + 0.30 * orderScore + 0.30 * closeScore + 0.15 * compScore; return { total, parts: { startScore, orderScore, closeScore, compScore }}; }
Feedback Mapping
if (parts.startScore < 0.5) hint('Mulai dari titik atas'); if (parts.orderScore < 0.5) hint('Coba ikuti urutan: 1 lalu 2 lalu 3'); if (parts.closeScore < 0.5) hint('Garis kamu agak miring — coba lurus'); if (parts.compScore < 0.5) hint('Belum selesai — masih ada garis'); if (total >= 0.85) celebrate('Bagus! Bentukmu rapi'); else if (total >= 0.65) celebrate('Sudah bagus, ayo lagi'); else encourage('Boleh coba lagi pelan-pelan');
Edge Cases
  • Anak terlalu cepat, hanya 1 titik per stroke: minimum point count = 4 sebelum scoring; di bawah itu skor 0.
  • Layar di-rotate saat menggambar: stroke direset, toast "Coba lagi ya, layarnya tadi diputar".
  • Multi-touch palm rejection: hanya stroke pertama per pointerdown yang dihitung.
  • Huruf dengan multiple valid stroke orders (mis. T bisa atas-dulu atau samping-dulu): target punya orderVariants, ambil maksimum.

#42 · Build Now
Impact: Very High Safety: Low Month 1 · Sprint 3
MVP

Pohon skill per subject (Math / Reading / Writing / Emotion / Calm). Node unlock berdasarkan mastery threshold dari attempt log, bukan jumlah main. Layar parent menampilkan 1-3 skill terlemah.

Data Skeleton
SKILL_TAXONOMY = { math: ['count_to_5','count_to_10', 'add_within_10','sub_within_10','make_10'], reading: ['letter_sound','first_letter', 'build_word','picture_word'], writing: ['trace_start','stroke_order','path_accuracy'], emotion: ['identify_emotion','body_cue','safe_action'], calm: ['inhale_exhale','complete_cycle'] }; mastery(skill) = wma(last_20_attempts.accuracy) unlock(node) = parents_mastery_all >= 0.70
Acceptance
  • Skill node update otomatis dari attempt event.
  • Node anak hanya unlock kalau semua parent mastery ≥70%.
  • Parent screen menampilkan 1-3 weak skill per minggu.
Algorithm — Node Render & Unlock Cascade
// Pakai Block B untuk mastery, lalu cascade unlock anak function renderTree(subject) { const nodes = SKILL_TAXONOMY[subject].map(id => ({ id, parents: SKILL_PARENTS[id] || [], mastery: masteryOf(id), status: 'locked' })); // Unlock cascade — root selalu unlocked for (const n of nodes) { if (n.parents.length === 0) n.status = 'unlocked'; } let changed = true; while (changed) { changed = false; for (const n of nodes) { if (n.status === 'locked' && n.parents.every(p => masteryOf(p) >= 0.70)) { n.status = 'unlocked'; changed = true; } if (n.status === 'unlocked' && n.mastery >= 0.85) n.status = 'mastered'; } } return nodes; }

  • Node mastered: outline berubah dari grey ke gold. Pulse 1 detik, lalu static.
  • Parent panel weak-skill: chip merah-muda lembut (#FECACA bg, #991B1B text), bukan red flash.

D · Pokemon Balance — BST Normalize 500

Anti-imba legendary
Impact: Fairness core Safety: Low All matches
Prinsip

Setiap Pokemon punya BST asli (Base Stat Total). Magikarp BST 200, Mewtwo BST 680. Selisihnya 3.4x — kalau dipakai langsung, anak yang punya Mewtwo selalu menang. Di PvP, semua Pokemon di-rescale ke BST 500 sehingga Magikarp = Mewtwo dari sisi total kekuatan. Perbedaan tetap ada di distribusi stat (Magikarp lambat tapi tahan; Mewtwo cepat tapi rapuh) — tapi totalnya sama.

Formula Normalize
const PVP_BST_CAP = 500; function normalize(pkm) { const stats = { hp: pkm.hp, atk: pkm.atk, def: pkm.def, spd: pkm.spd }; const bst = stats.hp + stats.atk + stats.def + stats.spd; if (bst <= 0) return { ...pkm, ...stats }; const k = PVP_BST_CAP / bst; // ratio preserved, floor minimum 60 untuk hindari div by zero const out = { hp: Math.max(60, Math.round(stats.hp * k)), atk: Math.max(60, Math.round(stats.atk * k)), def: Math.max(60, Math.round(stats.def * k)), spd: Math.max(60, Math.round(stats.spd * k)) }; // Re-distribute jika minimum floor menyebabkan total melebihi cap const total = out.hp + out.atk + out.def + out.spd; if (total > PVP_BST_CAP) { const excess = total - PVP_BST_CAP; // Strip dari stat tertinggi terlebih dahulu const sorted = ['hp','atk','def','spd'].sort((a,b) => out[b]-out[a]); for (const k2 of sorted) { if (excess <= 0) break; const removable = Math.min(out[k2] - 60, excess); out[k2] -= removable; } } return { ...pkm, ...out }; }

Damage Formula (Deterministic + Speed + Correctness)
// Tidak ada RNG. Tidak ada crit. Tidak ada miss. // Faktor baru: speed (waktu jawab) + correctness (benar/salah). function damage(move, atk, def, ctx) { // ctx = { correct: boolean, answerTimeMs: number } const base = move.power; // 18..34 (Block E) const offense = atk.atk; // post-normalize 60-125 const defense = def.def; // post-normalize 60-125 const ratio = offense / defense; // ~ 0.5 .. 2.0 const typeMult = typeEffective(move.type, def.type); // 0.5/0.75/1/1.25/1.5 const stab = atk.types.includes(move.type) ? 1.25 : 1.0; // — faktor baru — const correctnessMult = correctnessFactor(ctx.correct); const speedMult = speedFactor(ctx.answerTimeMs); const dmg = base * ratio * typeMult * stab * correctnessMult * speedMult * 0.4; return Math.max(0, Math.round(dmg)); // floor 0 jika salah jawab } function correctnessFactor(correct) { return correct ? 1.0 : 0.0; // salah → 0 damage } function speedFactor(ms) { // Clamp 0..∞. Cap di 1.5x (≤2s), turun ke 0.6x di ≥15s. if (ms <= 2000) return 1.5; // super fast if (ms >= 15000) return 0.6; // very slow // Linear interpolate return 1.5 - (ms - 2000) / 13000 * 0.9; // 1.5 → 0.6 }

Rules — yang DI-DISABLE di PvP

M · Anti-Bug Guarantees — No Infinite Loop, No Deadlock

Reliability discipline
Impact: Stability Safety: Low Pre-ship gate
Kelas Bug yang Wajib Di-Block
  1. Infinite loop — bracket advance, state machine, sudden death, animation queue.
  2. Deadlock — phase tidak transisi karena event tidak terbangkitkan.
  3. Race condition — tap dobel, animation overlap, state mutation paralel.
  4. Memory leak — event listener tidak di-unsubscribe, history log tumbuh tanpa cap.
  5. UI freeze — main thread blocked oleh sync compute (e.g., damage sim).
  6. Touch handling — double-tap, ghost click, multi-touch confusion.
  7. Lifecycle — backgrounded → forgrounded animation kerja ulang, state stale.
  8. Storage corruption — JSON parse error pada resume, mengkrash flow.
