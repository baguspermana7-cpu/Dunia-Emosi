1. Konteks & Mengapa Sekarang

Dunia Emosi sudah melewati marathon v55.0 → v55.27: 24+ commit, 16 bug ditutup (B-201 → B-216), 3 ask owner dipenuhi (A-301 standing, A-302 Thomas BGM, A-303 anti-collision), 17 lesson dipropagasi (L195 → L211).

Stack sekarang: vanilla JS + Pixi 8 + DOM. Total 25+ game (g6 sampai g25 + train games). Engine yang sudah dipakai luas:

  • PIXI.Application (g13c, g14, g15, g16, g17, g19, g20, g21, g22, g23, g24)
  • train-bg-engine.js + obstacle-engine.js + battle-sprite-engine.js (shared)

Pertanyaan: apakah stack ini sudah ceiling? Atau masih banyak head-room untuk grow tanpa migrasi?

Jawaban jujur — keduanya bisa benar tergantung tujuan:

  • Kalau owner mau 3D dunia eksploratif, kompleks particle, photorealistic shader → Pixi 8 = ceiling. Unity/Godot menang.
  • Kalau owner mau 2D edukatif super polished, kid-friendly, fast iteration, ringan di HP murah → Pixi 8 belum ada ceiling. Tinggal pasang sidecar libraries.

3. Unity 6 LTS

unity.com · Owner's first suggestion ("engine yang bisa anda kontrol pakai command kan?")

Powerful but heavy Reserve for native APK era

Sample Code — render Casey JR moving sprite (C# MonoBehaviour)

// CaseyController.cs
using UnityEngine;

public class CaseyController : MonoBehaviour {
  public Sprite caseyTexture;
  public float speed = 5f;
  private Rigidbody2D rb;

  void Start() {
    rb = GetComponent<Rigidbody2D>();
    GetComponent<SpriteRenderer>().sprite = caseyTexture;
  }

  void FixedUpdate() {
    float dx = Input.GetAxis("Horizontal") * speed;
    rb.linearVelocity = new Vector2(dx, rb.linearVelocity.y);
  }
}

Dev workflow

Owner edit CaseyController.cs di Visual Studio → Save → Switch ke Unity Editor → Wait for domain reload (3–6 detik) → Hit Play → Test di Game window → Tweak inspector → Repeat. Build WebGL untuk test di browser asli = 90–180 detik per build.

Pros (kids' game)

  • 3D + 2D dalam satu engine
  • Asset Store luas (free + paid sprites/sounds/effects)
  • Native APK via Build → Android (one-click)
  • Mature animation system (Animator + Timeline)
  • CLI buildable: Unity -batchmode -executeMethod Build.BuildPlayer

Cons (kids' game)

  • WebGL bundle 5–10 MB → kids tunggu lama di HP murah
  • Owner harus belajar C# (bahasa baru)
  • Iterasi lambat (build cycle 90+ detik)
  • Overkill untuk 2D edukatif sederhana
  • Migrasi 25 game ≈ 6 bulan kerja

Migration plan (kalau dipilih)

POC scope: port games/g6.html (word racer, ~1.25 K LOC) ke Unity 6.
  1. Install Unity Hub + 6 LTS (~6 GB disk).
  2. Buat project 2D Mobile WebGL target.
  3. Import car sprites + Indonesian word list.
  4. Tulis CarController.cs + WordSpawner.cs + UIManager.cs.
  5. Build WebGL bundle → host di subfolder Vercel.
  6. Side-by-side load comparison vs g6.html existing.
Estimasi: 2 minggu untuk satu game POC. 25 game × 2 minggu = ~12 bulan.

Best balance if migration appetite changes later

Sample Code — Casey JR moving sprite (GDScript)

# casey.gd
extends CharacterBody2D

@export var speed: float = 300.0
@export var casey_sprite: Texture2D

func _ready() -> void:
    $Sprite2D.texture = casey_sprite

func _physics_process(delta: float) -> void:
    var dir := Input.get_axis("ui_left", "ui_right")
    velocity.x = dir * speed
    move_and_slide()

Dev workflow

Edit casey.gd di Godot Editor → Save (Ctrl+S) → F5 Play scene → Live (no rebuild). HTML5 export = 1 menu click + 20 detik. Native APK = same project, export Android template. Iterasi cepat, hampir setara Pixi.

Pros (kids' game)

  • Bundle HTML5 ringan (2–3 MB vs Unity 5–10)
  • Native APK + HTML5 dari source yang sama
  • GDScript mudah (mirip Python, low ceiling)
  • Free, MIT, no royalty, no Pro tier
  • CLI: godot --headless --export ...
  • 2D engine kelas-1 (lebih baik dari Unity 2D)

Cons (kids' game)

  • Owner harus belajar GDScript (bahasa baru)
  • Smaller community vs Unity (lesson rarer di YouTube)
  • Migrasi 25 game ≈ 3–4 bulan
  • Tooling ecosystem masih tumbuh (Godot 4 baru)
  • Asset library belum sebesar Unity

Migration plan (kalau dipilih)

POC scope: port games/g6.html ke Godot 4.
  1. Install Godot 4.3+ (single 100 MB binary, no installer needed).
  2. Buat project Mobile Web target.
  3. Import car sprites sebagai Texture2D resources.
  4. Tulis vehicle_picker.gd + race.gd + word_quiz.gd.
  5. Export HTML5 → host di subfolder Vercel.
  6. Side-by-side dengan Pixi g6.
Estimasi: 1 minggu untuk POC. 25 game × 1 minggu = ~6 bulan.

Sample Code — Casey JR moving sprite (Phaser 3)

// CaseyScene.js
class CaseyScene extends Phaser.Scene {
  preload() {
    this.load.image('casey', 'assets/train/caseyjr-body.webp')
  }
  create() {
    this.casey = this.physics.add.sprite(200, 300, 'casey')
    this.casey.setCollideWorldBounds(true)
    this.cursors = this.input.keyboard.createCursorKeys()
  }
  update() {
    this.casey.setVelocityX(0)
    if (this.cursors.left.isDown)  this.casey.setVelocityX(-200)
    if (this.cursors.right.isDown) this.casey.setVelocityX(200)
  }
}

Dev workflow

Edit CaseyScene.js → save → browser refresh. No build step. vite bisa di-pakai untuk hot-reload + module bundling, tapi opsional. Sama cepat dengan Pixi sekarang.

Pros (kids' game)

  • 100% JS — owner sudah fluent
  • 7-year mature, lots of kids-game examples
  • Arcade physics + Matter physics built-in
  • Bundle 500 KB → kids load instant
  • Migrasi game-by-game, no full rewrite
  • Tween + animation system built-in (Pixi tidak)

Cons (kids' game)

  • Belum sebagus Godot/Unity untuk 3D
  • Capacitor wrap untuk APK (tidak senatif Godot)
  • Migrasi tetap butuh time (6-8 minggu untuk 25 game)
  • API style berbeda dari Pixi raw, butuh adaptasi

Migration plan (kalau dipilih)

POC scope: port games/g6.html ke Phaser 3.

  2. Buat games/g6-phaser.html baru (parallel ke existing).

7. Rekomendasi & Discussion

🏆 Primary recommendation

Tetap di PixiJS 8, tambah 4 sidecar libraries incremental

Match dengan kedua constraint owner: web/PWA + incremental. Stack existing 100% dipakai. Per-minggu ada upgrade yang visible (v55.29 Howler, v55.30 Matter, v55.31 Tone, v55.32 GSAP).

Trade-off jujur: ceiling 3D + native APK akan tetap di Pixi (artinya: not as high as Unity). Tapi untuk kids' 2D edukatif di browser, ceiling itu belum dipakai sama sekali. Naikkan saja yang sekarang.

Backup options

  • POC Phaser 3 (1 minggu) — kalau owner mau actually test rasa migrasi sebelum commit. Port g6.html ke Phaser, side-by-side dengan existing.
  • Godot 4 untuk native APK era (later) — kalau owner publish ke Play Store nanti, revisit. Bukan untuk sekarang.
  • Unity 6 LTS (skip atau later) — bundle WebGL 5–10 MB terlalu berat untuk kids' 3G. C# learning curve tinggi. Reserve untuk 3D ambition / native APK serius.
