🗄️ Panduan Supabase — Akun Math 7 Slot

Ikuti 5 langkah ini sekali saja. Tinggal copy-paste. Setelah selesai, kirim Project URL + anon key ke saya — nanti saya sambungkan ke game (kode client). Jangan bagikan service_role key.

  1. Buat project: buka supabase.com/dashboard → New project (atau pakai project yang sudah ada). Tunggu ±2 menit sampai aktif.
  2. Aktifkan login: menu Authentication → Providers → nyalakan Email (atau Anonymous kalau mau tanpa daftar).
  3. Jalankan SQL: menu SQL Editor → New query → copy blok SQL di bawah → paste → Run. (Aman diulang; pakai if not exists.)
  4. Ambil kunci: menu Settings → API → copy Project URL dan anon public key.
  5. Aktifkan (1 baris): sync sudah pre-wired di game. Tambahkan SATU baris ini sebelum <script src="data/math-cloud.js"> di games/kuis-matematika.html (ganti url + anon key kamu):
    <script>window.MATH_SUPABASE={url:'https://xxx.supabase.co',anonKey:'eyJ...'}</script>
    Selesai — sync 7-slot + leaderboard nyala. Tanpa baris ini game tetap 100% lokal (aman). Data lokal (stars/level/coins/gems/trophies + unlock kodok slot-7 & gym-pokemon) tersimpan ke cloud. Kalau ragu, kirim URL+anon key ke saya, saya yang pasang.
-- ============ Dunia Emosi · Akun Math 7 Slot ============
-- 1) Tabel: sampai 7 slot pemain per akun. Tiap slot menyimpan seluruh
--    progres (stars/level/accuracy/streak/coins/gems/trophies + unlock,
--    termasuk kodok slot-7 & opsi gym-pokemon) sebagai JSON.
create table if not exists public.math_players (
  id         uuid primary key default gen_random_uuid(),
  owner      uuid not null references auth.users(id) on delete cascade,
  slot       smallint not null check (slot between 1 and 7),
  name       text not null default 'Pemain',
  avatar     text default '🐸',
  data       jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now(),
  unique (owner, slot)
);

-- 2) Row Level Security: tiap user hanya bisa lihat/edit slot MILIKNYA.
alter table public.math_players enable row level security;
drop policy if exists "own read"   on public.math_players;
drop policy if exists "own insert" on public.math_players;
drop policy if exists "own update" on public.math_players;
drop policy if exists "own delete" on public.math_players;
create policy "own read"   on public.math_players for select using (auth.uid() = owner);
create policy "own insert" on public.math_players for insert with check (auth.uid() = owner);
create policy "own update" on public.math_players for update using (auth.uid() = owner) with check (auth.uid() = owner);
create policy "own delete" on public.math_players for delete using (auth.uid() = owner);

-- 3) Auto-update updated_at tiap kali baris diubah.
create or replace function public.touch_updated_at() returns trigger language plpgsql as $$
begin new.updated_at = now(); return new; end $$;
drop trigger if exists trg_touch on public.math_players;
create trigger trg_touch before update on public.math_players
  for each row execute function public.touch_updated_at();

-- 4) (Opsional) Leaderboard publik read-only: nama + trophies terbanyak.
create or replace view public.math_leaderboard as
  select name, coalesce((data->>'trophies')::int, 0) as trophies, updated_at
  from public.math_players
  order by coalesce((data->>'trophies')::int, 0) desc, updated_at desc
  limit 100;
grant select on public.math_leaderboard to anon, authenticated;

-- Selesai. Salin Project URL + anon key (Settings -> API), kirim ke dev.

Catatan: pendekatan ini pakai RLS (bukan service_role) — kunci rahasia tidak pernah masuk repo/browser. Kalau nanti mau anti-cheat lebih ketat (tulis lewat RPC SECURITY DEFINER seperti pola RZ), bisa ditambah belakangan.
